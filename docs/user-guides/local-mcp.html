Connect a local MCP client

Redirect Hub includes a local stdio server built with the official TypeScript MCP SDK. It calls the Hono API using a bearer token and does not open a network port. Use it only with an MCP host you trust, and give the token the narrowest scope that meets your needs.

Prepare the app

Install workspace dependencies, start the API with pnpm dev, and create the owner account in the React app at http://127.0.0.1:5173. In the app, open API access, create a token, and copy its value immediately; it is only shown once. Choose Read only for inspection and preview, or Read and write to also allow link and rule changes.

Add the server to an MCP host

Client configuration names vary. The example below uses a Node process directly so package-manager output cannot interfere with the stdio protocol. Replace the paths with the absolute paths on your machine:

{
  "mcpServers": {
    "redirect-hub": {
      "command": "node",
      "args": ["--import", "tsx", "src/mcp.ts"],
      "cwd": "D:\\WorkITAAI\\RDH\\apps\\api",
      "env": {
        "REDIRECT_HUB_API_URL": "http://127.0.0.1:8787",
        "REDIRECT_HUB_API_TOKEN": "paste-the-token-you-created-in-the-app"
      }
    }
  }
}

For a different checkout, change the working directory. Keep the token in your local MCP host configuration or secret store; do not commit it to the repository. The process writes MCP protocol messages to stdout and diagnostics to stderr.

Available tools

  • list_links, get_link, and list_routing_rules inspect the single owner's links and ordered routing rules.
  • simulate_redirect previews saved rules without redirecting or recording an analytics event.
  • get_analytics returns bot-filtered totals and available device, country, rule, and top-link aggregates.
  • create_link, update_link, create_routing_rule, and delete_routing_rule are only registered when REDIRECT_HUB_MCP_ALLOW_WRITES=1 is set for the process.

To register write tools, add REDIRECT_HUB_MCP_ALLOW_WRITES=1 to this MCP host's env object and restart the MCP process. The API still checks that the token has read/write scope; the environment switch alone does not grant API access. Read-only is the default. The API URL can point to loopback over HTTP or to a remote HTTPS endpoint; plain HTTP to a non-loopback host is rejected. Remote MCP transport is not provided.

Implementation status

This is an early local integration. The workspace build confirms TypeScript compilation, but a client/Inspector round trip has not yet been recorded. Tool behavior, database migration, and client-specific setup still need runtime review. See ticket T-0012 for acceptance criteria and open checks.

The server uses the official MCP TypeScript SDK. The SDK's stdio guide documents the local process transport and stdout/stderr requirement.
