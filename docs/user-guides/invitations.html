Invite a read-only workspace member

Owners can share links to let another person inspect a workspace's links, routing rules, and analytics. Invitations are manually shared bearer links; Redirect Hub does not email them.

Create and share an invitation

  1. Open Workspace in the app navigation.
  2. Select Create invite link, then copy the URL from the one-time result.
  3. Send the URL to the intended person using a channel you trust. The full URL is shown only when created; the invitation history shows status and expiry, not the secret.

Each invite link expires exactly seven days after creation, can be redeemed once, and can be revoked by the workspace owner before redemption.

Redeem an invitation

The recipient opens the link and creates a new account with an email address and password. The email address is not verified, and no email or notification is sent. Once accepted, the recipient can switch between their personal workspace and the invited workspace.

Access and bearer-link safety

Invited members can read workspace links, routing rules, tags, and workspace analytics, and can preview routing with the visitor simulator. They cannot create or change links, rules, or tags, manage invitations, or use API tokens or MCP for the shared workspace.

Anyone who obtains an unused invite URL can claim it. Share it only with the intended recipient, avoid public posts, and revoke it if it was shared by mistake. A recipient's entered email is not verified. Invitation links do not grant API or MCP access.

See the workspace and invitation technical notes for the authorization and storage model.
