Build a link with UTM tracking

Use optional campaign fields to add consistent analytics parameters to a short link's destination.

Create a tracked link

  1. Open Links and choose Create link.
  2. Enter a name and an HTTP(S) destination.
  3. Under Campaign tracking, fill in any of the five fields: Source, Medium, Campaign, Term, and Content.
  4. Review Final destination preview as you edit. It shows the destination URL after the configured tracking values are applied.
  5. Create the short link. To change or clear tracking values later, open that link's Settings, edit the fields, and save.

How destination parameters work

The saved values apply after the service chooses the link's default or matching rule destination. For each standard UTM key, existing occurrences are removed case-insensitively; each non-empty configured value is then added once using its lowercase key. A blank field therefore removes that UTM key from the destination.

Other query parameters are kept, including repeated keys and their order. The destination fragment is preserved. The visitor's query string on the short URL is ignored and is not forwarded.

Field limits

Each value is trimmed at its ends and accepts up to 200 Unicode code points. Interior spaces and Unicode characters are allowed and URL-encoded in the preview and redirect. Values longer than the limit or non-string API values are rejected with field-specific validation errors.
