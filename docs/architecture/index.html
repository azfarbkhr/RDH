Architecture

The new application separates a React browser interface, a Hono API, and SQLite persistence.

Current request flow

Hono validates links and routing rules, checks the signed-in owner session, and writes link, rule, and click-event data to SQLite. One ordered resolver serves both live short-link redirects and the visitor simulator: a rule matches when all conditions it defines match, and the first match wins. If no rule matches, the link's default destination is used. Simulation does not record an event. Live redirects record time, coarse device class, optional country code, referrer hostname, matched rule, and bot flag. Raw IP addresses and full user-agent strings are not stored. Node's built-in node:sqlite avoids a native package build step.

After destination selection, a shared URL composer applies each link's optional UTM source, medium, campaign, term, and content values. It removes every case-insensitive occurrence of those five keys from the selected destination, then appends the saved non-empty values once under canonical lower-case names. Other repeated query pairs and the fragment remain intact. The same composer powers the browser preview, simulator response, and live redirect. Query parameters sent to the short URL are ignored.

Current boundary

This is one local instance with an initial owner account. Registration closes after setup. Account invitations and shared workspaces are not implemented. Analytics excludes requests identified as bots and currently reports totals, recent totals, device groups, top links, and available country and matched-rule breakdowns. Country is unknown unless COUNTRY_HEADER_PROVIDER=cloudflare is configured behind a trusted proxy that overwrites CF-IPCountry; the application must not trust this header from arbitrary clients. Date filters, retention controls, token expiry, rate limiting, and broader API coverage remain in the ticket queue.

The local MCP stdio process calls the authenticated Hono API with a bearer token. It registers read tools by default and exposes mutation tools only when a read/write token is supplied and an explicit process setting enables writes. Revoked tokens are denied by the API. The stdio process does not expose another network listener. The default API address is loopback; non-loopback API URLs require HTTPS. PUBLIC_BASE_URL provides a stable short-link origin behind a reverse proxy. Token expiry, rate limiting, and remote MCP transport remain future work.

The earlier Django implementation remains under redirect_hub/ while the new stack is developed under apps/. Deployment, data migration, and replacing the old entry point are undecided.
