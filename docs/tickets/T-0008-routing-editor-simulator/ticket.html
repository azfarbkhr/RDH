Build the routing editor and visitor simulator

Ticket: T-0008. Delivery role: ui-developer. Relative effort: M. S = localized addition, M = cross-layer work, L = infrastructure or complex runtime work. These are planning estimates, not commitments.

Lifecycle, priority, dependencies, and ticket path are maintained only in the queue, sourced from tickets.jsonl.

Outcome

Add readable ordered rule cards, country/device selectors, visible default destination, accessible reordering, and a side-by-side visitor simulator in link details.

Current evidence

The React link cards now include an ordered routing-rule editor with add, remove, up/down controls, country/device conditions, and a visitor simulator. The simulator calls the shared Hono resolver and does not record a click. It shows the selected URL and matched rule number or default destination. Editing existing conditions, an explanation trace, and previewing unsaved rules remain open.

Feature inspiration: Dub Links, inspected 8 November 2026. The scope and effort are Redirect Hub recommendations, not claims about Dub implementation cost. See research and source limits and owner direction and planning assumptions.
