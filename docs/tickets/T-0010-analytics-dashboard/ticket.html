Outcome

Add an analytics tab with date-range traffic, country/device/referrer breakdowns, destination and rule matches, fallback share, and CSV export. Use labeled synthetic data for demos.

Current evidence

The current React workspace presents total and last-seven-day bot-filtered click counts. It shows country-code and matched-rule aggregates when those values are available; the authenticated Hono endpoint also returns device groups and top links. Date filters, charts, referrer breakdowns, fallback share, pagination, and CSV export are not implemented.
