Outcome

Make the existing Django application pleasant to use. Redesign the authenticated shell, login/register, link list, create/edit, and link-detail shell using neutral surfaces, one accent, readable typography, spacing tokens, and subtle borders. Keep Django templates. Route users to the application, with no marketing landing page.
