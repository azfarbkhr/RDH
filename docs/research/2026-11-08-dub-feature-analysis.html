Dub feature analysis and proposed scope

Research date: 8 November 2026. Small configuration and presentation additions offer the quickest improvements. Reliable routing, analytics, and MCP need shared backend behavior and explicit verification. Relative effort is inferred from this repository, not measured delivery time.

Verified competitor observations

Dub Links presents short links, QR codes, targeting, analytics, and developer integrations. Dub Links.

Its create-link schema includes tags, folders, archival, expiration, passwords, UTM fields, device/geographic destinations, and weighted variants. Dub create-link reference.

The UTM guide describes a builder for campaign parameters. Dub UTM builder. Expiration supports a date/time and an optional alternate destination. Dub link expiration.

Dub documents local and remote MCP offerings and links to separate Links MCP documentation. MCP is therefore an integration benefit rather than a novel competitor distinction. This analysis did not test Dub's MCP tool set. Dub MCP documentation.

The official MCP specification defines stdio and Streamable HTTP transports. The backlog separates local-process support from remote-client connectivity. Official MCP transport specification.

Repository baseline

Inspected redirect_hub/webapp/models.py, views.py, forms.py, tests.py, application templates, and URL configuration. Existing behavior is accounts, owner-scoped link management, and one-target temporary redirects. There are no rule/event models or meaningful application tests in the inspected webapp module. A stock-template website exists in the repository, but the owner wants the GitHub README as the public showcase.

Deliberate boundaries

Do not copy Dub branding, page content, or commercial workflows. Affiliate payouts, billing, enterprise SSO, conversion attribution, deep links, link cloaking, and rich custom social previews are excluded from this backlog. Preview generation requires crawler behavior, image hosting, and metadata choices beyond a small UI addition. Native-app deep links add platform configuration. They are not quick wins here.

Research limits

Public documentation was read, not a paid workspace or the Dub codebase. Pricing and plan limits are irrelevant to this self-hosted proposal and were not used for priority. An attempted QR help-page URL and two navigation click calls did not resolve; QR existence is supported by the Links page, and no unsupported QR customization details are assumed. SDK/protocol versions and geolocation licensing must be checked at implementation time.
