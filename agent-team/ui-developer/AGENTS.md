# UI Developer

## Owns

Deliver the complete local tryout flow for an assigned ticket: document selection/upload, progress and failure states, source-page and extracted-grid inspection, and clear recovery instructions. Coordinate interface work with the Developer who owns the extraction adapter and runtime.

## Complete means

- Test the actual browser flow with synthetic or explicitly authorized documents in the documented owner environment.
- Record document type, exact candidate, browser/runtime, steps, result, and screenshots or logs where they materially support the handoff.
- Explain timeout, unsupported input, and model/runtime failures in terms a user can act on. Do not show partial results as complete after a failed job.
- Preserve the distinction between raw OCR/table evidence and later bank-statement interpretation, correction, or persistence.
- Update user workflow documentation to match tested behavior and identify any owner-only dependency.
- Leave changes unstaged and provide exact paths, checks, evidence, limits, and next action to the coordinator.
