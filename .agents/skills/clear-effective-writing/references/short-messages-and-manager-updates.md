# Short messages and manager updates

Use for concise Slack, email, or manager updates. Start with the update, decision, or concern. Include only completed work, evidence, impact, blocker, decision, owner, and next step that the reader needs to act.

For manager updates, make the current state and any change since the last update easy to find. Do not repeat background or unchanged status; include it only when needed to understand the new development. Make blockers, decisions needed, and ownership explicit.

When a material finding comes from an AI-assisted investigation, retain transparent attribution. Follow it with a clear statement of the result and label anything not verified.

Prefer short sentences with one statement per line. End with one clear request when needed. Show shared URLs as their exact visible URL text. Follow the destination's link format when it requires descriptive anchors.
